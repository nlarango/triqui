# 🎮 ¡Triqui! El Juego Clásico en Versión Digital

## 🎯 Descripción del Proyecto

**Triqui** es una versión digital interactiva y colorida del clásico juego de Tic-Tac-Toe, diseñada especialmente para que los niños y niñas disfruten mientras juegan y desarrollan sus habilidades lógicas.

Este juego permite que los jugadores compitan contra la computadora en un tablero de 3x3, con una interfaz gráfica visualmente atractiva, sonidos y animaciones que hacen la experiencia más divertida y envolvente.

## ✨ Características

- 🎨 **Interfaz Gráfica Colorida**: Diseño amigable y llamativo para niños
- 🤖 **IA Inteligente**: Juega contra una computadora que desafía tu lógica
- 🎵 **Efectos Visuales**: Animaciones y cambios de color que celebran tus movimientos
- 🔄 **Modo de Juego Rápido**: Juegos rápidos y emocionantes
- 🏆 **Contador de Victorias**: Mantén track de tus ganancias
- 📱 **Interfaz Responsiva**: Fácil de usar en cualquier pantalla

## 🚀 Cómo Jugar

1. **Inicia el juego** ejecutando el script principal
2. **Haz clic en cualquier casilla** del tablero para colocar tu símbolo (X)
3. **La computadora responderá** automáticamente (O)
4. **¡Gana!** Consigue tres en línea (horizontal, vertical o diagonal) antes que tu oponente
5. **Juega nuevamente** - Cada partida es una nueva oportunidad

## 💻 Requisitos

- Python 3.7 o superior
- Tkinter (incluido en Python por defecto)

## 📊 Reglas del Juego

- Dos jugadores comparten un tablero de 3x3
- Cada jugador coloca su símbolo (X o O) en turnos alternos
- El primer jugador en conseguir tres símbolos en línea recta (horizontal, vertical o diagonal) gana
- Si se llenan todas las casillas sin ganador, el juego es un empate
